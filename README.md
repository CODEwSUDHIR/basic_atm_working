# 🏧 ATM Working System

A simple **ATM Working System** that simulates basic ATM operations such as checking balance, depositing money, and withdrawing money. 💳💰

## ✨ Features

* 💰 **Check Balance** – View your current account balance.
* ➕ **Deposit Money** – Add money to your account.
* ➖ **Withdraw Money** – Withdraw money if sufficient balance is available.
* 🔐 **Simple & Secure** – Basic ATM-style menu system.
* 🔄 **Multiple Transactions** – Perform multiple operations in one session.
* 🚪 **Exit** – Safely exit the ATM system.

## 🛠️ Operations

```text
🏧 ATM SYSTEM
│
├── 💰 Check Balance
├── ➕ Deposit
├── ➖ Withdraw
└── 🚪 Exit
```

## 💡 How It Works

1. Start the ATM program.
2. Select an operation from the menu.
3. Check your balance, deposit money, or withdraw money.
4. The balance is updated after every transaction.
5. Select **Exit** when you are finished.
